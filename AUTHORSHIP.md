# Authorship

*Beaks and Blood: Tabe Pocket* is an original game concept and design by **Nicolas Lanza**. That covers the setting, the Roukha, the scouts, the company, and every design decision recorded in the README.

The v1 code, map data, tests and documentation were written for Nicolas by **Grok Bot**, an AI assistant, working to his direction. No third-party game code or assets are included. Sounds are generated procedurally in the browser.

Third-party *tools* used only to build and test (not shipped in `dist/`): TypeScript, esbuild, vitest, tsx. Each is under its own license.
